# ChatGPT / Codex 套餐余量（v0.4.0 实验功能）

> 非官方实验接口：读取结果可能随 ChatGPT 网页版变动而失效，字段与可用性不做承诺。

## 1. 功能说明

此功能读取当前登录 ChatGPT/Codex 账户的**套餐余量**（5 小时窗口与每周窗口的剩余百分比），
并把结果作为独立显示项接入浮岛默认轮播与自定义分组。它**不是** Provider API Key 账户：
不会创建 ChatGPT 账户条目，也不会影响余额聚合。

## 2. 启用与风险确认

- 在“Codex 套餐”页勾选“我已了解风险，允许创建登录会话并联网读取”。
- 首次勾选即视为风险确认（CodexPlanConsentVersion == 1）。
- 取消勾选会同时关闭功能、自动刷新并清除套餐快照（不删除登录 Profile，Profile 由
  “断开并清除”删除）。

## 3. WebView2 登录

- 确认后点击“打开登录窗口”，在专用 WebView2 窗口登录 chatgpt.com。
- 该会话使用独立 Profile：%LOCALAPPDATA%/BalanceIsland/WebView2/ChatGPTPlan，
  不与系统 Edge 或其他功能共享。
- 关闭登录窗口只是隐藏；会话保留，供后台自动刷新使用。

## 4. 首次读取

- 登录完成后回到“Codex 套餐”页，点击“读取套餐余量”。
- 读取只在当前页面为 https://chatgpt.com 时执行；脚本只返回筛选后的窗口字段。

## 5. 自动更新与手动限速

- “每 5 分钟自动更新”固定 5 分钟，不可调短；以最近一次网络尝试为准。
- 首次启用自动刷新会弹出独立确认，说明隐藏窗口后仍会后台联网。
- 手动“读取套餐余量”同样受 5 分钟间隔限制；不足时按钮不会触发请求。

## 6. 浮岛与分组

- 勾选“显示在浮岛”后，套餐项追加到**默认轮播**（在 API 账户之后）。
- 自定义分组编辑区可勾选“包含 ChatGPT/Codex 套餐余量”；轮播分组允许只包含套餐。
- 聚合分组不允许包含套餐，避免把百分比计入金额汇总。

## 7. 错误处理

| 错误 | 表现与处理 |
|---|---|
| 401/403（登录失效） | 保留最后成功快照，暂停自动刷新；点击“重试并恢复”重新登录后恢复 |
| 429（请求受限） | 保留最后成功快照，暂停自动刷新；**不自动重试**，等窗口过后手动恢复 |
| 网络失败 | 显示错误类别，下次自动刷新仍会尝试 |
| 解析失败 | 显示错误类别，不影响已保存快照 |
| 运行时错误 | 显示错误类别，不自动重建浏览器进程 |

暂停后普通“读取套餐余量”保持禁用，显示“重试并恢复”按钮；不足 5 分钟时按钮显示
剩余等待时间。

## 8. 隐藏、退出与重启

- 隐藏登录窗口不影响后台刷新。
- 退出应用时按 service → browser/window → coordinator 顺序停止并释放。
- 重启后若仍处于已确认且启用自动刷新状态，会懒加载会话并继续；不会在未确认时联网。

## 9. 断开并清除

- “断开并清除”清除专用 Profile 的全部浏览数据、删除 UDF、清空套餐快照并停止调度。
- Profile 删除失败时记录 CodexPlanProfileCleanupPending，下次初始化前重试。

## 10. 风险与限制

- 同一 Windows 用户下的其他进程理论上可访问该 Profile；会话视同密码，请勿分享机器。
- 接口为网页版私有接口，可能变更、限流或失效；本功能不提供任何保证。
- 诊断数据仅包含错误类别与状态码，不包含响应正文、Cookie、Token 或完整接口响应。
- 不应分享读取时的诊断日志或截图中的敏感会话信息。

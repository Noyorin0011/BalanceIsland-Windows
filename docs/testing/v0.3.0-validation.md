## v0.3.0 功能验收

### 主题与外观

- [x] System / Light / Dark 三种主题模式有自动化覆盖。
- [x] 高对比度优先级保留。
- [x] 正常、异常、预警、临界四状态颜色及五套预设已纳入测试。
- [x] 自定义颜色只接受 `#RRGGBB` / `#AARRGGBB`。
- [x] 预警边界为 `警戒线 < 余额 <= 警戒线 × 1.15`；临界优先于异常，异常优先于预警。

### 显示分组

- [x] 轮播分组允许混合 Provider。
- [x] 聚合分组限制同一 Provider。
- [x] 聚合时 Error 成员不参与数值求和。
- [x] 币种不一致时不进行错误聚合。
- [x] 无数值余额的 Provider 显示有效/错误 Key 统计而不伪造余额。

### 环境 API 与 Key 安全

- [x] 扫描进程、当前用户、系统三级环境变量。
- [x] 导入前必须由用户明确勾选。
- [x] 通用 `sk-` 候选不自动猜 Provider。
- [x] 轮换后的环境 Key 会经过 `ApiKeySanitizer.Clean`。
- [x] 长 Key 只显示安全后缀；短 Key 使用不可逆占位符。
- [x] Provider 错误文本经过脱敏处理，不应泄露完整 Key。
- [x] 完整 Key 仍只保存在 Windows Credential Manager，不写入 `state.json`。

### 通知

- [x] 预警、临界、异常三类通知可独立开关。
- [x] 状态进入触发而非停留重复触发。
- [x] Windows 11 支持重要通知时使用 urgent；Windows 10 使用普通通知。
- [x] 原生通知失败时回退托盘气泡。
- [x] Windows 11 VM 已确认测试 Toast 能实际弹出。

### 升级与回滚

升级前建议退出应用并备份：

`%LOCALAPPDATA%\BalanceIsland\state.json`

完整 API Key 不在该 JSON 中；它们位于当前 Windows 用户的 Credential Manager。需要回滚时先退出应用，再恢复对应版本的 `state.json` 备份。旧版本会忽略无法识别的新字段。

### v0.3.0 浮岛定位复验项

PR #20 保持产品版本为 v0.3.0，且不包含 Codex/WebView2 v0.4.0 功能。自动化与
Release 构建已经通过，但下列行为仍需在真实 `win11-24h2-vm` 中复验：

| 开始按钮 | Widgets | 期望位置 |
| --- | --- | --- |
| 居中 | 启用 | 浮岛左边缘优先贴近 Widgets 右侧，并保持在开始按钮左侧 |
| 居中 | 关闭 | 浮岛位于任务栏最左端，并保持在开始按钮左侧 |
| 左对齐 | 启用 | 浮岛位于开始/任务按钮右侧，右边框与 Widgets 左边缘保留 6px 并紧贴对齐 |
| 左对齐 | 关闭 | 浮岛位于开始/任务按钮右侧、通知区域左侧，不覆盖任何已识别元素 |

Widgets 只有在 UI Automation 快照中可见且非 offscreen 时才算启用。点击任务栏或桌面后，
浮岛应继续覆盖在任务栏表面，顶边保持与任务栏顶边一致，不被 Shell 盖住或向下偏移。
若任务栏带内没有足够的无重叠空间，浮岛临时移动到任务栏外侧上方。

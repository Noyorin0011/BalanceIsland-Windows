# Balance Island Windows v0.3.0 显示、分组与通知设计

## 目标

在 `v0.2.1` 基础上完成六项关联能力：可选择的应用深浅色、按余额状态变化的浮岛文字颜色、自定义轮播/聚合分组、经用户确认的环境 API Key 发现、可搜索且集中维护的 Provider 支持信息，以及可在 Windows 11 专注模式中显示的重要通知。应用内说明与 README 同步提供完整教程。

## 范围与兼容边界

- 目标版本为 `0.3.0`，支持 Windows 10 1809+、Windows 11、.NET 8、WPF 与现有 Win32 浮岛。
- 保持 `%LOCALAPPDATA%\BalanceIsland\state.json` 向后兼容。缺少新增字段的旧配置采用本文规定的默认值。
- 保留 Windows Credential Manager 存储手动 API Key 的行为。完整 Key 不进入状态 JSON、UI、日志或通知。
- 保留现有位置/尺寸预设、编辑浮岛、鼠标穿透、全屏隐藏、80ms 复核、5 秒兜底与九家 Provider 图标。
- 不在本次变更中引入 MSIX、完整 Windows App SDK Runtime、多显示器独立浮岛或新的 Provider 网络接口。
- 功能分支通过 PR 和 Windows CI 交付；未经用户明确要求不合并、不打标签、不发布。

## 1. 应用主题

新增持久化 `ThemeMode`：

- `System`：跟随 Windows 应用主题，系统切换后即时刷新。
- `Light`：固定浅色，忽略普通系统主题变化。
- `Dark`：固定深色，忽略普通系统主题变化。

旧配置默认 `System`。Windows 高对比度始终优先于上述选择，以系统颜色保证可访问性。主题变化必须同时刷新设置窗口、对话框、原生标题栏和动态资源；浮岛状态文字颜色由独立的状态色设置控制。

## 2. 浮岛状态颜色

状态区间采用以下精确定义：

| 状态 | 条件 | 默认颜色语义 |
| --- | --- | --- |
| 一般 | 没有更高优先级状态 | 白色/主题主色 |
| 异常变动 | 本次刷新满足账户异常变动阈值 | 紫色 |
| 高于警戒线 15% | `警戒线 < 余额 <= 警戒线 × 1.15` | 橙色 |
| 到达/低于警戒线 | `余额 <= 警戒线` | 红色 |

优先级为：到达/低于警戒线 > 异常变动 > 高于警戒线 15% > 一般。没有数值余额时只可能显示一般或异常状态。

提供五套内置色板：经典、薄荷、天空、珊瑚、青柠。每套都定义四种状态色。选择“自定义”后可分别填写 `#RRGGBB` 或 `#AARRGGBB`，输入无效时不保存并指出具体字段。设置页显示四项即时预览；保存后浮岛立即重绘。

## 3. 自定义显示分组

一个分组包含稳定 ID、名称、模式和账户 ID 集合。模式分为：

### 账户轮播

- 可混合不同 Provider。
- 浮岛按现有周期逐个轮换组内已启用账户。
- 账户原有“在浮岛显示”开关不限制显式分组成员；它只用于未选择分组的兼容模式。

### 同 Provider 聚合

- 首个账户确定 Provider，后续只能加入相同 Provider 的账户。
- 显示分组名、Provider、账户数，并合计可用余额和今日用量。
- 只合计币种一致且具有数值的字段。同 Provider 的当前实现应具有同一默认币种；若实际快照币种不一致，则显示“币种不一致”，不产生错误合计。
- 对仅验证 Key、没有数值余额的 Provider，显示“有效 Key 数 / 异常 Key 数”，不伪造余额。
- 组状态取成员中的最高严重级别；异常和余额通知仍标明实际触发账户的备注与 Key 后四位。

任何时候只选择一个当前分组。选择“未启用分组”时，继续按现有 `ShowInIsland` 账户开关轮播。删除账户时自动清理所有组成员；删除活动组时回到未启用分组；空组显示明确占位，不抛出异常。组名去除首尾空格且不能为空。

## 4. 集中 Provider 注册表

将当前散落的 Provider 元数据集中为单一注册表。每个条目包含：

- Provider 枚举与显示名称；
- 图标资源键；
- 默认货币与推荐刷新周期；
- 余额查询、用量查询或仅验证能力；
- 标准环境变量名；
- 可用于变量名识别的关键词；
- 可唯一识别 Provider 的 API Key 前缀；
- 使用限制与帮助文字。

添加账户搜索、环境扫描、支持类型列表、默认刷新设置和文档生成信息均读取同一注册表。以后新增 Provider 时，必须在此注册一次并同步获得上述入口；测试会检查每个 `Provider` 枚举都有且仅有一个注册条目。

添加账户区提供 Provider 搜索框，按显示名称和别名过滤。环境 API 页用列表展示全部支持类型、匹配方式、查询能力和限制，不再把所有说明塞进一个文本段落。

## 5. 环境 API Key 扫描与确认导入

扫描当前进程、当前用户和系统三级环境变量，按以下顺序匹配：

1. 标准环境变量名；
2. Provider 变量名关键词；
3. 可唯一识别的 Key 前缀，例如 `sk-or-`、`sk-ant-`、`sk-admin-`、`sk-proj-`、`AIza`、`xai-`。

普通 `sk-` 不能唯一识别 DeepSeek、Moonshot、SiliconFlow 等 Provider，不允许仅凭该前缀自动归类；必须同时匹配变量名或由用户在导入窗口明确选择 Provider。

扫描结果窗口显示复选框、变量名、作用域、匹配 Provider、匹配依据和 Key 后四位。默认全部不选。用户确认后只导入勾选项；取消不会修改配置。已存在的同一环境变量账户标记为“已导入”，不会重复创建。导入后的账户继续在每次刷新时动态读取环境变量值。

`EnvironmentAutoImportEnabled` 的旧语义改为“启动时提示扫描”。它可以自动打开扫描结果，但绝不未经确认添加账户。后台定时器不弹窗、不静默导入。

## 6. Windows 重要通知

使用系统原生 Toast 通知管道和桌面应用身份注册，不引入完整 Windows App SDK Runtime。Windows 11 支持时使用 Toast XML `scenario="urgent"`，使 Balance Island 可作为重要通知穿透专注模式。系统通知权限、用户的“重要通知”选择和组织策略始终拥有最终控制权，应用不得绕过用户明确禁用的设置。

Windows 10 或不支持 `urgent` 的系统发送普通 Toast。原生 Toast 注册或发送失败时，回退到现有托盘气泡，并在设置页显示降级状态。

三类通知可以分别开关，默认均开启：

- 首次进入“高于警戒线 15%”区间；
- 首次到达或低于警戒线；
- 本次刷新满足异常变动阈值。

余额状态只有从区间外进入区间时通知；持续停留不重复通知。恢复到区间外后再次进入可重新通知。从预警进入临界必须再通知一次。异常通知继续遵循账户现有冷却时间。通知包含 Provider、账户备注或 Key 后四位、前后余额/当前余额和触发原因，不包含完整 Key。

“刷新与通知”页提供三个事件开关、通知通道状态、Windows 重要通知权限说明和测试按钮。测试通知不修改真实告警参考状态。

## 7. UI 与教程

“显示与外观”页按以下卡片重排：

1. 应用主题；
2. 状态颜色与预览；
3. 显示分组管理；
4. 现有位置、尺寸和编辑模式。

环境 API 页包含 Provider 搜索/支持列表、扫描说明和“扫描环境”按钮。刷新与通知页包含三类重要通知设置、通道状态和测试按钮。

每张卡片包含用途说明和简短操作提示。README 增加六项功能的独立章节，说明入口、步骤、状态区间、分组模式、环境扫描隐私边界、专注模式权限与 Windows 10 降级行为。CHANGELOG 增加 `0.3.0` 条目。

## 数据迁移默认值

- `ThemeMode = System`
- `IslandColorTheme = Classic`
- 四个自定义颜色使用经典色板值
- `DisplayGroups = []`
- `ActiveDisplayGroupId = null`
- 三类通知开关均为 `true`
- 旧告警级别读取后按 1.15 新边界重新计算；不因启动迁移立即发送通知，只有后续真实刷新发生状态进入时才通知。

反序列化后的集合和颜色字段需要标准化，避免旧文件中的 `null` 或无效颜色造成启动失败。无法读取状态文件时保持现有安全行为：使用默认状态启动，不覆盖原文件，直到用户产生新的有效保存操作。

## 测试与验收

新增独立测试项目，至少覆盖：

- `warningLine`、`warningLine × 1.15` 两侧及等号边界；
- 临界、异常、预警和一般的视觉优先级；
- 状态进入、持续、恢复、再次进入和预警升级临界的通知去重；
- 标准变量名、变量名关键词、唯一前缀、通用 `sk-` 拒绝误判及重复环境账户；
- Provider 枚举与集中注册表一一对应；
- 轮播组混合 Provider、聚合组同 Provider 约束、币种不一致及无数值 Provider 统计；
- 删除账户/活动组后的清理；
- `v0.2.1` 最小 JSON 加载后的全部默认值；
- 自定义颜色格式校验。

CI 执行测试、Release build 和 win-x64 publish。人工验收矩阵：

| Windows 10 22H2 VM | 主题、分组、环境扫描、普通 Toast 降级、任务栏兼容布局与全屏隐藏 |

## 非目标

- 不合计不同 Provider 或不同币种的金额。
- 不根据不可唯一识别的通用 Key 前缀猜测 Provider。
- 不绕过 Windows 用户关闭的通知权限或组织策略。
- 不在通知、环境扫描列表或文档中显示完整 API Key。
- 不在本次版本加入云同步、远程设备识别或自动控制测试虚拟机。
